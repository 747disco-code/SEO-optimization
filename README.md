# 747 Disco - Sito Web per WordPress + Elementor

Questo repository contiene il sito web completo per 747 Disco, una location esclusiva per feste ed eventi a Roma.

## 📋 Contenuto del Progetto

### ⭐ **NUOVO: Sezioni Pronte per Elementor**
- `elementor-sections/` - **8 sezioni HTML** pronte da copiare/incollare in Elementor
  - Con CSS e JavaScript inline
  - Responsive design
  - Istruzioni complete in italiano
  - **Leggi la guida:** `elementor-sections/GUIDA-COMPLETA.md`

### 📁 Altri File
- `index.html` - Pagina HTML completa standalone (opzionale)
- `style.css` - CSS completo (opzionale)
- `script.js` - JavaScript (opzionale)
- `747disco_bck/` - Backup WordPress/Elementor originale
- `README.md` - Questo file

## 🚀 Come Usare (METODO RACCOMANDATO)

### ✅ Inserire in Elementor - FACILE!

1. **Apri la guida completa:**
   - Vai su `elementor-sections/GUIDA-COMPLETA.md`
   - Leggi le istruzioni passo-passo

2. **Procedura rapida:**
   - Crea pagina in WordPress
   - Modifica con Elementor
   - Aggiungi widget HTML
   - Copia/incolla codice da ogni file
   - Pubblica!

**Tempo: 30-60 minuti** ⏱️

### 📂 Le 8 Sezioni

1. `01-hero-section.html` - Slider principale
2. `02-intro-section.html` - Chi siamo
3. `03-reviews-section.html` - Recensioni
4. `04-contact-form.html` - Contatti
5. `05-events-grid.html` - Eventi
6. `06-photos-section.html` - Foto
7. `07-location-section.html` - Dove siamo
8. `08-mobile-cta.html` - Barra mobile

## 📝 Personalizzazione

### Cambiare Immagini
1. Carica in WordPress Media Library
2. Copia URL immagine
3. Sostituisci nel codice HTML

### Cambiare Colori
Ogni sezione ha CSS inline con:
```css
--color-gold: #917F59; /* Cambia qui */
```
