### Metodo 1: Import Tramite Elementor Tools (CONSIGLIATO) ⭐

1. **Vai su WordPress Dashboard**
2. **Elementor → Tools → Import / Export**
3. **Tab "Import"**
4. **Clicca "Choose File"**
5. **Seleziona `homepage-optimized-747disco.zip`**
6. **Clicca "Import Now"**
7. **Aspetta il completamento** (5-10 secondi)
8. **Vai su Pagine → Homepage → Modifica con Elementor**
9. **Clicca icona cartella (Template)**
10. **Cerca "747 Disco - Homepage Ottimizzata"**
11. **Clicca "Inserisci"**
12. **Salva e pubblica**

### Metodo 2: Import Tramite Template Library

3. **Clicca "Import Templates"** (in alto)
4. **Carica `homepage-optimized-747disco.zip`**

6. **Aspetta conferma importazione**

## 🆘 Problemi Comuni e Soluzioni

### ❌ Errore "File non valido"
**Soluzione:** Assicurati di aver scaricato il file ZIP completo, non il file JSON singolo.

### ❌ Template non compare dopo import
**Soluzione:** 
- Vai su Elementor → Template Salvati
- Verifica che "747 Disco - Homepage Ottimizzata" sia nella lista
- Ricarica la pagina

### ❌ Google Maps non funziona
**Soluzione:**
- Elementor richiede Google Maps API
- Vai su Elementor → Settings → Integrations
- Inserisci la tua Google Maps API Key

### ❌ Form Contact Form 7 non appare
**Soluzione:**
- Verifica che Contact Form 7 sia installato e attivo
- Crea un form se non esiste
- Copia l'ID del form (numero)
- Sostituisci `461` con il tuo ID nel widget

### ❌ Font non corretti
**Soluzione:**
- Vai su Elementor → Custom Fonts
- Carica Mr Dafoe e Work Sans se non presenti
- Oppure usa Google Fonts automaticamente
